# Formatting Showcase
This page demonstrates all the cool things you can do with **Quartz** and **Obsidian**.

## 1. Callouts
Enhance your notes with these colorful blocks.

> [!note] Note
> This is a standard note. Good for general info.

> [!important] Important
> Use this for key takeaways!

> [!warning] Warning
> Watch out! This indicates something risky.

> [!tip] Pro Tip
> You can even nest callouts if you're feeling wild.

## 2. Syntax Highlighting
Quartz supports code blocks for almost any language.

```typescript
// quartz.config.ts
export const config = {
  theme: {
    typography: {
      header: "Schibsted Grotesk",
      body: "Source Sans Pro",
    },
  },
}
```
